# 🔐 Password Strength Analyzer & Security Suggestion Tool

A beginner-friendly cybersecurity web application that analyzes password strength, detects common security weaknesses, provides security suggestions, and generates secure random passwords.

---

## 📌 Project Overview

The Password Strength Analyzer helps users understand the security characteristics of a password without storing the password.

The application analyzes passwords temporarily and provides:

- Security score
- Password classification
- Security findings
- Security suggestions
- Password policy results
- Password metrics
- Entropy estimate
- Secure password generation

---

## ✨ Features

### 🔍 Password Analysis

The analyzer checks:

- Password length
- Lowercase letters
- Uppercase letters
- Numbers
- Symbols
- Character uniqueness
- Repeated characters
- Repeated substrings
- Sequential patterns
- Keyboard patterns
- Common passwords
- Predictable password structures
